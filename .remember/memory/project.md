# Proje Tercihleri ve Kurallar

- Kodlarda yorum satırı kullanılmaz (dosya yolu hariç).
- Yalnızca istenen yapılır, ek açıklama veya özellik eklenmez.
- Bellek güncellemesi yalnızca kullanıcı isterse yapılır.
- Her dosya adı benzersiz olmalı.
- Yanıtlar Türkçe ve kısa olmalı.
- Kodlar dinamik olmalı, hardcoded olmamalı.
- .env dosyası okunmaz, .env.example kullanılabilir.
- pm2 ve npx kullanılmaz.
- Her zaman önce npm install çalıştırılır.
- Sadece istenen yapılır, yeni özellik eklenmez.
